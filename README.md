# Eldritch IME · 奇诡音形

这里保存 **「奇诡音形测试第一版」**：基于夜莺 3.0 的音形取码实验，采用 **两码小鹤双拼＋一码首根＋一码字族序位**。

第四码按同一三编码族的读音字频排序，使用第三码另一只手的固定键序。它不再取末根；序位在生成码表时固定，日常输入不会随个人使用频率改变。

当前是规则码表和验证数据，尚未完成输入法实打与学习体验测试。

## 四码怎样组成

1. **前两码：小鹤双拼。** 例如「植、枝、帜」都是 `vi`。
2. **第三码：首根所在键。** 本版木、巾都在 `p`，因此这三个字属于 `vip` 字族。
3. **第四码：字族内的序位。** 同音码、同首根键的所有字音共同排序，不同具体首根也可能属于同族。

| 第三码所在手 | 第四码固定顺序 |
|---|---|
| 左手 | `j l k n i h m o p u y` |
| 右手 | `e d r s f b t a c w g v q x z` |

手区约定：左手 `qwertasdfgzxcvb`，右手 `yuiophjklnm`。

`vip` 的第三码 `p` 在右手，因此第四码依次取 `e、d、r、s……`：

| 字 | 首根 | 全码 | 最短规则码 |
|---|---|---|---|
| 植 | 木 | `vipe` | `vip` |
| 枝 | 木 | `vipd` | `vipd` |
| 帜 | 巾 | `vipr` | `vipr` |
| 桎 | 木 | `vips` | `vips` |
| 栉 | 木 | `vipf` | `vipf` |

固定一二简沿用夜莺 3.0；每族在其余有正频率的读音中，把三简给最高频项，全码保留。已有一二简的字也占用其全码的序位。

| 指标 | 夜莺 3.0 | 奇诡第一版 |
|---|---:|---:|

| 实际第三→第四码当量，低为好 | 1.355029 | **1.097437** |

| 前1500字必须四码的读音项 | 122 | 105 |
| 前1500字 × 前1万词，必须全码碰撞 | 0 | 0 |
| 前1500字 × 前3万词，必须全码碰撞 | 1 | **0** |
| 前3500字 × 前1万词，必须全码碰撞 | 4 | **0** |

第三码当量基本持平，第四码当量约下降 19%。三项常用字词指标为零，扩大到完整词码集合仍有碰撞。重码和当量都是固定数据下的规则测量，未模拟整句、选重和实际上屏。

## 本地核验

需要 Python 3，使用标准库即可：

```bash
python3 tools/evaluate.py --check
```

它会从根键布局重新生成所有编码，核对全码唯一性、字库覆盖、三四码异手、固定一二简、原根组归并、当量、完整单字表及二维字词避重数据。

## 来源与实验状态

拆分、字音基准、当量表及比较基线来自 [losWater/Nightingale](https://github.com/losWater/Nightingale) 的 **v3.0**，固定提交为 `4a3c126341dfbe134146329a1c327cfff1580b50`。源文件路径与 Git blob SHA 保存在 [统计汇总](reports/summary.json) 中。

全字库参与容量与碰撞检查；扩展字缺少本实验所用的分读音字频，因此不参与手感加权，零频同分按 Unicode 码点排序。顺序第四码增加了字族序位的记忆负担，实际学习成本和手感仍需试打评估。
