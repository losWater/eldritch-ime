# 评价口径与来源

## 覆盖与全码

容量与碰撞覆盖全部 15,496 字、15,844 个字／音码身份。多音字按不同音码分别统计。每个 ABX 族同时容纳共键的所有具体首根；在合并字族后重新排序第四码、分配三简并计算指标。

第一版全码唯一。固定一二简和新三简作为额外入口保留，最终单字表共 20,275 行。

## 读音字频与手感

手感采用夜莺 3.0 字音基准中的分读音字频，归一化到每百万，总量约为 1,000,000。扩展字缺少本轮使用的分读音频率，权重为零，但仍参加容量和撞词计数。

- 实际第二→第三码当量：只统计最短规则码长至少为三的读音，排除固定一二简。
- 实际第三→第四码当量：只统计必须打全码的读音。
- 形码部分字均键对成本：排除固定一二简，累计码内键对；短码附空格，全码不附确认键，沿用来源仓库的成本约定。

键对当量不能替代实际输入速度、手指负担或学习实验。

## 字词避重

只计必须打四码的单字读音，其全码与二字词音码相同才计碰撞。同一字音撞多个词只算一次，不按字词对数计数。

前 N 字分层采用来源方案的规则：前 N 字主读音，加上读音频率达到第 N 字总字频阈值的次读音。前1500/3500/6000字档分别覆盖1522/3572/6186个读音身份。

测试词表前4万条为来源仓库的常用排序，后2万包含补位词；前5万、6万按该表的排序条目数取。与完整正式二字词固定码位的诊断属于不同词库口径。

第一版在三项常用避重范围为零，但完整正式词码集合仍有2753个必须全码字音项撞词。没有“全部字词无重码”的承诺。

## 固定来源与文件

数据来自 [Nightingale v3.0](https://github.com/losWater/Nightingale/tree/4a3c126341dfbe134146329a1c327cfff1580b50)，源路径和 blob SHA 见 [summary.json](../reports/summary.json)。

| 文件 | 内容 |
|---|---|
| data/input.json.gz | 标准化字音身份、具体首根、固定简码、3.0基线码、字频、当量矩阵、前3万词目标和完整正式词码集合 |
| data/reading-frequency.json.gz | 从3.0字音基准投影的字／小鹤音码／原读音频率，保持源排序，用于分层 |
| data/word-targets.json.gz | 来源6万词避重目标的词／码／源排名／来源分类，保持源排序 |
| data/layout.json | 第一版374根的最终键位、两手第四码顺序和搜索参数 |
| data/root-groups.json | 原归并、三处拆分后的132组及具体根形归属 |
| reports/summary.json | 第一版与3.0的冻结对照指标 |
| reports/word-clash-matrix.json | 全部字频档位与词频档位的累计碰撞表 |

JSON 数据采用 gzip 压缩以避免仓库中的大段重复文本，Python 标准库可直接读取。

## 实验边界

首根学习成本只通过保留原归并和轻量换键惩罚处理，仍有288个具体首根换键。第四码序位需要学习与记忆。所有验证是规则码表层面的计算，未测试输入引擎、整句、上屏、候选排序或人类学习效果。

随机启发式搜索不保证全局最优；保存的选定根键布局和码表可以精确复核。
